# RGB 세부 설정 — 0.3.0

오른쪽 **RGB 조명 → 세부 설정**에서 설정한다. 팬 자동 제어 중에도 열 수 있으며,
편집 중에는 장치를 변경하지 않고 **조명 설정 적용**을 누를 때만 전송한다.

| 항목 | 설정 범위 |
| --- | --- |
| 조명 켜기 | 현재 켜짐/꺼짐을 기본값으로 표시. 체크 상태를 적용 |
| 효과 | 단색, 호흡, 무지개, 파도, 점멸, 흐르는 색상, LED별 고정 색상, 색상 회전 |
| 밝기 | 0~100%, 화면은 5% 단위 |
| 효과 속도 | 1~10, 높은 값일수록 빠름. 고정 색상에서는 사용하지 않음 |
| 색상 | `#RRGGBB` HEX 6개와 색상 미리보기 |
| 호흡 색상 수 | 앞의 1~5개 색상을 순환 |
| 기본값/마지막 적용값 | 편집 화면에 불러오기. 적용 전에는 장치를 변경하지 않음 |

단색·파도·점멸은 색상 1을 사용한다. LED별 고정 색상은 여섯 LED 각각에 색상을 지정한다.
흐르는 색상과 회전은 여섯 색상을 사용하고 무지개는 고정 7색을 사용한다.
LED 번호는 프로토콜 순서이며 실제 장치의 어느 위치인지 육안으로 대조하지 않았다.
밝기 0%는 RGB 켜짐 상태에서도 실제 색상을 어둡게 만든다.

## 설정 저장 및 기존 색상 조회 제한

분석한 원본 SDK는 RGB 켜짐 상태를 조회하지만 기존 색상표를 읽는 명령은 확인되지 않았다.
따라서 새 앱도 기존 장치 색상표를 자동으로 읽어 표시하지 않는다.
창에 표시하는 값은 **이 PC에서 마지막으로 적용한 값** 또는 기본 제안값이다.
다른 프로그램/PC가 변경한 색상은 반영할 수 없다.

적용 성공 후 `%LocalAppData%\Bs2Cooler\rgb-settings.json`에 저장한다.
파일이 없거나 유효하지 않으면 기본 제안값을 표시하며 자동으로 장치에 쓰지 않는다.
**기본값 불러오기**, **마지막 적용값**도 장치에 바로 쓰지 않는다.
창을 닫아도 이미 적용한 조명은 유지하고, 아직 적용하지 않은 편집은 폐기한다.
USB 재연결/앱 재시작 때 저장된 조명을 자동 적용하지 않는다.

## 프로토콜 및 동시 제어

제조사 코드를 실행하지 않고 기존 분석 사본에서 전송 형식을 확인해 자체 코드를 작성했다.
RGB 표는 버전 0.2, LED 6개 × RGB 프레임 10개, 헤더 포함 186바이트이다.
전송 순서는 `0x41` 준비 → `0x47` 인덱스가 붙은 10바이트 조각 19개(마지막 6바이트)
→ `0x43` 완료 → `0x46` 켜짐 상태 적용이다. 각 단계의 성공 응답을 확인한다.

한 RGB 전송 전체가 끝날 때까지 같은 연결의 다른 명령을 대기시키고,
WPF에서도 적용 중에는 팬 제어 쓰기와 겹치지 않도록 처리한다.
팬은 직전 목표 속도를 유지하며 조명 전송이 끝나면 온도 자동 제어를 계속한다.
팬 모드, 단계, 저장 속도와 단계 표시등은 RGB 세부 적용으로 변경하지 않는다.

## 실제 검증 범위

- 실물 BS2 Pro `37D7:1002`, 펌웨어 `0.0.3.3`에서 8가지 효과의 준비/19조각/완료 명령 모두 성공 응답 확인.
- 시험 중 RGB는 꺼서 점멸 효과가 실제로 발광하지 않게 했으며 기존 RGB/단계 표시등 꺼짐을 유지했다.
- 팬 목표 1400 RPM과 저장 속도 `1400,2400,2700,2700`이 유지됨을 확인했다.
- 기존 색상표는 읽을 수 없어 최초 시험 후 청록 단색 `#55CBB0`, 밝기 50%를 첫 앱 설정으로 저장했다. 이는 원래 색상표의 정확한 복원을 의미하지 않는다.
- WPF에서 잘못된 HEX 거부, LED별 색상/밝기 적용, 파일 저장, 마지막 앱 설정 복원과 최소 창 크기 레이아웃을 확인했다.
- GPU 온도 자동 제어 중에도 RGB 창을 열어 실물 적용/복원 후 팬 자동 제어 중지/기존 RPM 복원까지 확인했다.
- CPU/GPU 기준에서도 CPU 약 63~64°C / GPU 53°C → 팬 목표 2400 RPM 상태에서 RGB 편집/실물 적용/기존 앱 색상표 복원을 수행하고, 자동 중지 후 1400 RPM 복원까지 확인했다.
- 장치 응답과 설정 전송을 검증했으며 실제 발광 색상/방향/효과 모양을 카메라나 육안으로 확인한 것은 아니다.
- 프로토콜/온도/RGB 테스트 34개 통과. HEX·값 범위, LED/프레임 배치, 21개 명령 분할 및 체크섬 규칙을 포함한다.
