# GitHub 프로필 업적 확인

2026-10-16 KST, 대상 계정 [Grokeen](https://github.com/Grokeen).
사용자가 요청한 최대 5종을 검토했으며 기존 보유와 신규 획득을 구분한다.

| 업적 | 작업 시작 시 확인 | 이번 작업 |
| --- | --- | --- |
| Pull Shark | 프로필 이미지/alt에 이미 표시 | 실제 Windows CI 및 Release 변경을 PR로 병합해 추가 이력을 남김. 새 배지나 등급 상승은 별도 확인 필요 |
| Quickdraw | 프로필 이미지/alt에 이미 표시 | 기존 보유 확인. 배지용 이슈/PR을 반복 생성하지 않음 |
| YOLO | 프로필에서 표시되지 않음 | 개인 저장소 PR의 코드/CI 결과를 확인하고 정식 GitHub 리뷰 요청 없이 병합. 자동 부여/표시는 확인 후 보고 |
| Pair Extraordinaire | 프로필에서 표시되지 않음 | 실제 공동 작성자가 필요한 유형. 이번 작업에 타인의 공동 저자를 추가하지 않음 |
| Starstruck | 프로필에서 표시되지 않음 | 저장소가 받는 별과 관련된 유형. 현재 저장소 별 0개이며 타인의 반응을 대신 만들지 않음 |

같은 업적의 활동 횟수는 누적/등급에 영향을 줄 수 있지만 별도의 같은 배지 5개를 만드는 기능은 아니다.
공식 [GitHub 프로필 문서](https://docs.github.com/en/account-and-profile/reference/profile-reference#earning-achievements)는
업적이 활동 이벤트에 따라 표시되며 현재 공개 미리보기로 변경될 수 있음을 설명한다.
세부 임계값과 지연에 대한 커뮤니티 답변은 서로 다른 주장이 있어 부여를 확정하는 근거로 사용하지 않는다.

조건에 대한 참고는 GitHub Community의
[Pull Shark](https://github.com/orgs/community/discussions/18610),
[YOLO 등 업적](https://github.com/orgs/community/discussions/175547),
[실제 공동 작성](https://github.com/orgs/community/discussions/20481),
[저장소 별](https://github.com/orgs/community/discussions/20577) 토론이다.
이 표는 해당 토론의 조언과 프로필 관찰을 구분한 작업 기록이며 GitHub의 확정된 부여 API 명세가 아니다.

실제 빌드/병합/배포 결과와 최종 프로필 관찰 시각은 [작업 보고서](WORK_LOG.md)에 남긴다.
