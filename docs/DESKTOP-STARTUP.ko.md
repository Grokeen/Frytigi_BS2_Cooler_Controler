# 자동 실행과 백그라운드 사용

BS2 Cooler 0.4.0은 Windows 로그인 후 창을 띄우지 않고 알림 영역(트레이)에서 실행됩니다.
이 PC에는 `C:\Program Files\BS2 Cooler\Bs2Cooler.exe`로 설치했고 바탕화면과 시작 메뉴에 바로가기를 만들었습니다.

## 창과 트레이

- 창의 **X** 또는 최소화는 트레이로 숨깁니다. 온도 수집과 이미 시작한 자동 팬 제어는 계속됩니다.
- 팬 아이콘을 두 번 누르거나 우클릭 → **창 열기**를 선택하면 창이 돌아옵니다.
- 앱/바로가기를 다시 실행해도 기존 창을 열며 중복 실행하지 않습니다.
- **온도 자동 제어 시작/중지**는 창을 열지 않고 팬 자동 제어를 바꿉니다.
- **종료 · 기존 팬 설정 복원**을 선택하면 자동 제어 시작 전 팬 모드/RPM을 복원하고 완전히 종료합니다.
  수동으로 적용한 설정은 유지됩니다. USB가 끊겼거나 Windows가 프로세스를 강제 종료하면 복원 성공을 보장할 수 없습니다.
- Windows가 아이콘을 숨기면 알림 영역의 **숨겨진 아이콘 표시(^)**에서 찾을 수 있습니다.
- 0.4.1부터 우클릭 메뉴 맨 위에 CPU/GPU 현재 온도를 표시합니다. 마우스를 올린 도움말과 창 상단에도 표시하며 약 2초마다 갱신합니다.

## 로그인할 때의 동작

트레이 메뉴의 **로그인 시 자동 실행**으로 등록 여부를 바꿉니다.
기본값은 **앱만 실행**이며 시작만으로 팬 속도나 조명을 변경하지 않습니다.
**자동 실행 시 온도 제어도 시작**을 체크하면 다음 로그인부터 저장된 CPU/GPU 기준과 성능/저소음 곡선으로 자동 제어를 시작합니다.
USB 연결과 선택한 센서가 준비될 때까지 대기합니다. RGB 색상표는 자동으로 적용하지 않습니다.

자동 실행은 현재 사용자 SID별 `BS2 Cooler-<사용자 SID>` 예약 작업을 사용합니다.
사용자가 로그인한 뒤 10초 지연, 대화형 세션, 최고 권한으로 다음 명령을 실행합니다.

```text
"C:\Program Files\BS2 Cooler\Bs2Cooler.exe" --background --startup
```

CPU 온도 읽기에 관리자 권한이 필요하므로 설치/작업 등록은 한 번 관리자 권한으로 수행합니다.
그 뒤 등록된 작업의 로그인 실행에는 매번 UAC 창을 띄우지 않습니다. 암호를 저장하거나 SYSTEM 서비스로 실행하지 않습니다.
프로그램은 일반 사용자가 수정할 수 없는 Program Files 사본에서 실행합니다.
등록된 상태에서 바로가기만 실행하면 같은 예약 작업을 통해 CPU 센서 권한으로 창을 엽니다.
자동 실행을 해제한 뒤 일반 권한으로 실행하면 CPU 센서 권한 버튼을 사용할 수 있습니다.

부팅 직후 로그인 전에는 실행되지 않습니다. 트레이가 필요한 앱이므로 **해당 사용자의 로그인 후 실행**입니다.
현재 PC에서는 작업 등록 내용과 같은 예약 작업을 수동 실행한 결과를 검증했습니다.
실제 재부팅/로그아웃, 절전 복귀, USB 케이블 분리·재연결은 이번 시험에 포함하지 않았습니다.

## 설치 또는 업데이트

소스에서 Release 배포본을 만든 후 **관리자 PowerShell**에서 실행합니다.

```powershell
.\tools\Publish-App.ps1
.\tools\Install-Desktop.ps1
```

ZIP을 풀어 사용하는 경우 그 폴더의 `Install-Desktop.ps1`을 실행합니다.
스크립트는 EXE 해시 확인, 기존 앱의 정상 종료, Program Files 복사, 예약 작업 등록, 바로가기 생성과 백그라운드 시작을 수행합니다.
기존 자동 제어 시작 여부는 유지합니다. 명시적으로 바꾸려면 `-StartupCooling On` 또는 `Off`를 지정합니다.
이미 실행 중인 앱이 종료되지 않으면 강제 종료하지 않고 업데이트를 중단합니다.

자동 실행 해제는 트레이 메뉴 또는 관리자 PowerShell에서 다음과 같이 수행할 수 있습니다.

```powershell
& 'C:\Program Files\BS2 Cooler\Bs2Cooler.exe' --disable-startup --background
```

해제는 다음 로그인부터의 실행을 막으며 현재 앱을 종료하지 않습니다. 현재 앱은 트레이의 종료 메뉴로 종료합니다.

## 저장 파일과 아이콘

- `%LocalAppData%\Bs2Cooler\app-settings.json`: 자동 실행 시 온도 제어 여부, 온도 기준과 곡선
- `%LocalAppData%\Bs2Cooler\desktop.log`: 로컬 시작/종료/오류 기록(크기 제한 및 이전 파일 보관)
- `%LocalAppData%\Bs2Cooler\rgb-settings.json`: 마지막으로 적용한 RGB 설정

직접 제작한 팬 아이콘을 실행 파일·창·트레이·바로가기에 적용했습니다.
[SVG 원본](../assets/Bs2Cooler.svg), [PNG 미리보기](../assets/Bs2Cooler.png), [Windows ICO](../assets/Bs2Cooler.ico)를 제공합니다.
ICO는 16~256px의 9개 크기를 포함하며 `tools/Generate-Icon.ps1`로 SVG에서 다시 생성할 수 있습니다.
