BS2 Cooler 0.3.0

Windows용 BS2 Pro USB 쿨러 제어 앱입니다.

1. BS2 Pro를 데이터 통신용 USB 케이블로 연결하고 쿨러 전원을 켭니다.
2. Bs2Cooler.exe를 실행합니다. 장치를 자동으로 찾습니다.
3. 단계를 선택하고 RPM을 조정한 뒤 '속도 적용'을 누릅니다.
   단계 버튼은 저장된 속도를 화면에 불러옵니다. 실제 변경은 적용 버튼을 눌러야 합니다.
4. 오른쪽 버튼으로 RGB 조명과 단계 표시등을 켜고 끌 수 있습니다.
5. RGB 조명의 '세부 설정'에서 효과, 밝기, 속도, HEX 색상 6개를 편집하고 '조명 설정 적용'을 누릅니다.
   'RGB 조명 켜기' 체크 상태도 적용합니다. 체크하지 않으면 색상표를 적용해도 조명은 꺼져 있습니다.
   단색/파도/점멸은 색상 1, LED별 색상/회전/흐르는 색상은 6색, 호흡은 앞의 1~5색을 사용합니다.
   무지개는 고정 7색입니다. 밝기는 0~100%, 속도는 1~10입니다.
   편집/미리보기/기본값 불러오기는 장치를 변경하지 않습니다. 적용해야 전송합니다.
   기존 장치 색상표는 조회하지 못하므로 이 PC의 마지막 적용값 또는 기본 제안값을 표시합니다.
   마지막 적용값: %LocalAppData%\Bs2Cooler\rgb-settings.json
   앱 재시작/재연결 때 색상을 자동 적용하지 않습니다. RGB 상세: docs/RGB-LIGHTING.ko.md

현재 전원에 맞는 RPM 한계를 표시합니다.
일반 전원 최대 2700 / QC 최대 3300 / PD 최대 4000 RPM.
속도 변경에는 현재 선택한 단계의 저장 속도 변경도 포함됩니다.
앱을 시작하거나 다시 연결하는 것만으로 속도나 조명을 바꾸지는 않습니다.
수동 제어 중 앱을 종료하면 적용된 수동 설정은 유지됩니다.

온도 자동 제어:
1. '온도 자동' 탭을 선택합니다.
2. 기본 기준은 'CPU / GPU 중 더 높은 온도'입니다. GPU 기준만 선택할 수도 있습니다.
   CPU 권한 안내가 보이면 'CPU 온도 권한으로 다시 실행'을 눌러 Windows 관리자 승인을 허용합니다.
3. 성능/저소음 곡선을 고르고 '자동 제어 시작'을 누릅니다.
4. 중지하거나 앱을 정상 종료하면 자동 시작 전의 모드/RPM으로 복원합니다.
자동 모드에서는 수동 속도 적용을 막습니다. 원래 저장된 4단계 RPM은 바꾸지 않습니다.
90도 이상에서는 현재 전원이 허용하는 최대 풍량을 사용합니다.
온도를 읽을 수 없거나 8초 넘게 만료되면 최대 풍량을 유지합니다.
연결이 끊겨 복원 명령을 보낼 수 없는 경우는 정상 종료 복원과 구분됩니다.

GPU 온도는 기존 NVIDIA 드라이버를 사용합니다. 별도 GPU 프로그램을 설치하지 않습니다.
현재 PC에서 GPU 온도/자동 제어는 확인했습니다.
CPU 온도는 공식 서명 PawnIO 드라이버가 별도로 설정되어 있어야 읽을 수 있습니다.
현재 PC에는 사용자 허용에 따라 공식 PawnIO 2.2.0을 설치했으며 실제 CPU 온도 읽기를 확인했습니다.
드라이버의 기본 접근 권한에 따라 CPU 온도 읽기에는 앱의 관리자 실행이 필요합니다.
일반 실행에서 접근이 거부되면 재실행 버튼을 표시합니다. GPU 기준은 일반 권한으로 사용할 수 있습니다.
CPU 센서의 권한을 모든 사용자에게 개방하지 않습니다. 드라이버 설치/시작을 앱이 자동 수행하지 않습니다.
CPU 센서 설정 안내: docs/AUTOMATIC-COOLING.ko.md

앱에는 설치 프로그램, 자동 업데이트, 인터넷 통신이 없습니다.
관리자 권한 요청은 CPU 온도 권한 버튼을 직접 누를 때만 발생합니다.
제조사 EXE/DLL, 제조사 서비스, 별도 HID 라이브러리를 사용하지 않습니다.
Windows 기본 HID 기능과 Microsoft .NET Desktop Runtime 9를 사용합니다.
현재 PC에서는 런타임이 설치되어 있어 바로 실행할 수 있습니다.
다른 PC에서는 Microsoft .NET Desktop Runtime 9 (x64)가 필요합니다.

원본 Space Station의 화면과 서비스가 동시에 제어하면 설정이 충돌할 수 있습니다.
원본을 종료하고 사용하는 것을 권장합니다. 앱은 원본 서비스를 자동 조작하지 않습니다.

이 버전은 수동/온도 자동 팬 제어, 조명 켜기/끄기, RGB 세부 편집을 지원합니다.
Bluetooth는 포함하지 않습니다.
스마트 모드에서 수동 적용 시 스마트 모드 해제 명령을 먼저 보냅니다.
자동 모드 진입/임시 RPM/중지/이전 수동 설정 복원은 실물에서 검증했습니다.
