BS2 Cooler 0.1.0

Windows용 BS2 Pro USB 쿨러 제어 앱입니다.

1. BS2 Pro를 데이터 통신용 USB 케이블로 연결하고 쿨러 전원을 켭니다.
2. Bs2Cooler.exe를 실행합니다. 장치를 자동으로 찾습니다.
3. 단계를 선택하고 RPM을 조정한 뒤 '속도 적용'을 누릅니다.
   단계 버튼은 저장된 속도를 화면에 불러옵니다. 실제 변경은 적용 버튼을 눌러야 합니다.
4. 오른쪽 버튼으로 RGB 조명과 단계 표시등을 켜고 끌 수 있습니다.

현재 전원에 맞는 RPM 한계를 표시합니다.
일반 전원 최대 2700 / QC 최대 3300 / PD 최대 4000 RPM.
속도 변경에는 현재 선택한 단계의 저장 속도 변경도 포함됩니다.
앱을 시작하거나 다시 연결하는 것만으로 속도나 조명을 바꾸지는 않습니다.
앱을 종료해도 쿨러에 적용된 수동 설정은 유지됩니다.

설치 프로그램, 자동 업데이트, 인터넷 통신, 관리자 권한 요청이 없습니다.
제조사 EXE/DLL, 제조사 서비스, 별도 HID 라이브러리를 사용하지 않습니다.
Windows 기본 HID 기능과 Microsoft .NET Desktop Runtime 9를 사용합니다.
현재 PC에서는 런타임이 설치되어 있어 바로 실행할 수 있습니다.
다른 PC에서는 Microsoft .NET Desktop Runtime 9 (x64)가 필요합니다.

원본 Space Station의 화면과 서비스가 동시에 제어하면 설정이 충돌할 수 있습니다.
원본을 종료하고 사용하는 것을 권장합니다. 앱은 원본 서비스를 자동 조작하지 않습니다.

이 버전은 수동 팬 제어와 조명 켜기/끄기를 지원합니다.
CPU/GPU 온도 기반 자동 곡선, Bluetooth, RGB 색상/효과 편집은 포함하지 않습니다.
스마트 모드에서 수동 적용 시 스마트 모드 해제 명령을 먼저 보냅니다.
스마트 모드 전환은 현재 실물에서 별도 검증이 남아 있습니다.
