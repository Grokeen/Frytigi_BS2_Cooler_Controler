The unmodified signed IntelMSR.bin is embedded in Bs2Cooler.Windows.
Corresponding IntelMSR.p, include files, upstream README and COPYING are
provided in third_party/PawnIO.Modules/0.2.11 in the repository and package.
Rebuild Bs2Cooler.sln to replace the embedded module with another module.
The Pawn compiler and SDK build information are described by upstream.

This application does not install or start the PawnIO kernel driver.
CPU sensing is optional and requires a separately configured official signed
PawnIO driver. This application only calls the temperature-related read-MSR
path; it does not expose write-MSR functions.

NVIDIA NVML is not redistributed. GPU sensing uses nvml.dll from the NVIDIA
display driver already installed in Windows System32. No NVIDIA driver or
installer is bundled or installed by this application.
